# Painel de Manutenção Preditiva – Fresadora CNC (AI4I 2020)

Dashboard interativo (HTML + Chart.js, arquivo único) da disciplina *Inteligência Artificial e Programação para Engenharia* – Experiência Prática IV.

- Dados: AI4I 2020 Predictive Maintenance Dataset (UCI, ID 601, CC BY 4.0), agregados.
- Turnos, lotes, datas e ordens de serviço são **derivados por premissas de modelagem** (1 ciclo a cada 30 min a partir de 01/09/2026 06:00).
- Estado de cada ciclo dado por um agente híbrido (regras físicas + Random Forest).

Abra `index.html` em qualquer navegador; funciona offline.
